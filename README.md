## 🚀 Featured Projects

### 💳 FastBill — Billing & Payment Management System
> `Angular` `Node.js` `Laravel` `MySQL` `Microservices` `JWT` `RBAC`

A **production-grade** billing platform with a complete payment lifecycle and multi-role access system.

- ⚡ **3-role RBAC** (Admin, Biller, Payment Poster) with JWT auth and Angular route-level guards
- ⚡ **Microservices** — Node.js handled auth & user management; Laravel owned billing & document APIs
- ⚡ **End-to-end bill generation** — visit selection, procedure codes, insurance coverage, discount/tax calc, **NF2 PDF auto-generation**
- ⚡ **Payment module** — Cash, Cheque, Bank Transfer, Credit/Debit Card, Insurance with real-time balance updates
- ⚡ **Document management** — file type & size validation (PDF, JPG, PNG, DOCX, max 5MB), versioning, audit trail
- ⚡ **Role-specific dashboards** — billing summary, payment statistics, full admin oversight with export

---

### 🛒 Dukanify — Full-Stack E-Commerce Platform (MEAN)
> `Angular` `Node.js` `Express.js` `MongoDB` `Google OAuth` `JWT` `Cron Jobs`

A **production-grade multi-role marketplace** with enterprise-level security and automation.

- ⚡ **Multi-role** (Buyer, Seller, Admin) with complete order lifecycle — `pending → in_progress → ready → fulfilled`
- ⚡ **Dual auth** — Email OTP with expiry/resend + Google OAuth 2.0, JWT access/refresh token rotation
- ⚡ **Separate Admin backend** for seller approvals, store verification & reporting — clean separation of concerns
- ⚡ **Automated cron jobs** — order cleanup, OTP expiry, inventory alerts, daily/weekly sales analytics
- ⚡ **Enterprise security** — Helmet headers, CORS allowlist, rate limiting, Mongo injection guards, XSS protection, Zod validation
- ⚡ **Product catalog** — search, filters, pagination, inventory tracking, Multer image uploads

---

### 📚 LMS — Learning Management System
> `Angular` `Laravel` `Cloudinary` `JWT` `RBAC` `HTTP Interceptors`

A **full-stack LMS** with content delivery, progress tracking and role-based dashboards.

- ⚡ Course creation, lesson uploads, **progress tracking**, notifications & role-based dashboards
- ⚡ Complete auth system — JWT, Angular Guards, route protection, **HTTP interceptors**, RBAC
- ⚡ **Cloudinary** integration for scalable media storage & delivery
- ⚡ Reusable Angular component library with protected routing & structured API communication
